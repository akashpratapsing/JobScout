Daily search

Optional. JobScout must be running at the scheduled time. Missed days are not caught up.

A run starts only within 20 minutes of the scheduled time. This avoids firing an old search hours late.

Job sources

Only sources with permitted public access are listed. Configure boards for the ATS platforms you want to search.

Source boards are public identifiers (for example a Greenhouse board token), not passwords.

Integrated sources

Live sources are fetched directly with rate limits and robots.txt checks where applicable.

Manual search links

These platforms do not offer public jobs APIs for this use case, or their terms restrict automated access. JobScout opens a search for you; it never scrapes or auto-applies.

Search history

Every run keeps source-level stats and errors so results stay traceable.

AI provider

Cloud AI only. JobScout never downloads a local model, never purchases credits, and never switches to a paid fallback.

Free-only mode is always on. OpenRouter models must end with :free. If a provider quota runs out, JobScout falls back to clearly labelled rules-based scoring and does not retry with a paid service.

Privacy

Minimize what leaves your machine and know exactly when it does.

If off, only the structured profile is sent. Job matching always sends only the structured profile and the job posting text, never your full resume.

Turn this off to delete the raw text immediately after extraction. Profile fields remain until you delete them.

Your data

Stored in data/app.json on this machine. Backups are kept locally for seven days.

Export JSON

Deleting all data removes your profile, jobs, search history, preferences, and encrypted API keys. This cannot be undone.

Scope & limitations

  • Discovery only. JobScout never auto-applies, fills forms, submits resumes, messages recruiters, or requests referrals.
  • No fake coverage. LinkedIn, Indeed, Glassdoor, Dice, Naukri, Foundit, Instahyre, Hirist, Cutshort, and Wellfound are not integrated because public, permitted job APIs are unavailable. Use the manual links.
  • Verification is best-effort. A last-verified timestamp means JobScout checked the URL. It is not a guarantee that the role is still open.
  • AI is advisory. Scores are evidence-based and capped when required skills, experience, or location eligibility do not fit. Always read the original posting.
